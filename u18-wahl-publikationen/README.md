## Inhalt

- `paper/U18_Paper_v6_Trying_Is_Not_Trusting.md` — Akademisches Manuskript (Englisch), Nachfolger von Paper v5. Kernänderungen gegenüber v5:
  - Korrigierte Methodenbeschreibung: Cluster-Zuweisung auf **Kommunenebene** (10 bayerische Pilot-Kommunen, BJR + StMD), nicht schulweise in München.
  - Neuausrichtung auf die aktuellste Analyselinie (Juni 2026): Akzeptanz-Trust-Asymmetrie (adjustiert +0,77 z vs. +0,24 z, Interaktion p ≈ 2×10⁻⁷), Diskriminanzvalidität (EFA, AVE, Fornell–Larcker, HTMT), Attenuationsanalyse (Vor-Einstellung CV9 als Vertrauensanker), Verifikations-Befund (~19 % Nutzung, Verständnis d = +0,19 n.s., TT4 ohne Modalitätseffekt).
  - Brown-Bag-Kritik vollständig eingearbeitet: Urbanitäts-Confound, Klassenkontext, Zugangswege zum Fragebogen, keine Prä-Messung (wahlrechtliches Verbot), Realness als mehrdimensionales Konstrukt (Faktorstruktur statt Alpha), 97 Freitext-Kommentare als Dummy/Moderator, fsQCA nur explorativ (Cutoff-Sensitivität), explorative Rahmung, einfaches Modell als Publikationsstrategie, Venue-Zielrichtung HICSS / I&M / GIQ.
